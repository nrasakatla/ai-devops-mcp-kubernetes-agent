## Upwork description (≤ 600 chars)

Public portfolio project demonstrating a real, reproducible AI-assisted
Kubernetes troubleshooting workflow. A read-only MCP server exposes diagnostic
tools (pod status, events, logs, node resources); a Python agent collects
evidence from a local kind cluster and an Ollama LLM (qwen3.5:9b) produces
plain-English incident reports with root cause and remediation. Detects
CrashLoopBackOff, OOMKilled, and Pending. Safety-first: read-only verbs, context
guard, advisory-only fixes, deterministic offline fallback. Includes tests, CI,
architecture diagram, and demo screenshots.
